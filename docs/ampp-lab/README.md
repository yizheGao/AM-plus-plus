## 关键结论（动态背景）

参考软件（LyricsBlossom 8.1）的背景是**封面派生的平滑色场**，不是粒子/光晕/频谱：
`BackdropMeshLayer`（≤24×24 网格）+ `GradientCS` 渐变 + 广域模糊回退 + 有序抖动。
实测帧间差 4–9/255，亮度中位约 75/255，角部时域方差最大。

本分支据此实现了两个可切换方案：

- **方案 A（还原）**：11×8 网格从封面取色，主色混合 0.75、明度 0.25–0.46、径向压暗 0.18，
  随机噪声抖动去色带。对齐参考的背景统计：亮度 75.7 / p90 82 / 饱和 0.37（参考 81.1 / 93.7 / 0.39）。
- **方案 B（自研）**：3 条沿正弦中心线铺开的光带，中心线基准高度、振幅、频率、横向漂移、
  行进亮带各用不同速率，支持运动速度与运动模式（舒缓/流动/律动）。

设置入口：设置 → AM++ → **背景光效**（关闭 / 封面渐变 / 极光），滑块随选择联动。

## 已知限制

- 参考软件的 52 个 shader 是 AES-256-GCM 加密的，密钥推导未完成，方案 A 属**行为复刻**。
- 无歌词曲目上逐词事件不触发，能量密度会下降（只剩换行）。
- 横竖屏切换时仍有一帧左右的过渡，未使用遮罩方案（试过，效果更差已回退）。
